- 문제를 여러 행사에 재사용하는 `CompetitionProblem` 릴리스 모델 추가
- 단답·출력 내장 비교 채점과 소스 코드 외부 샌드박스 대기열 경계 추가
- IOI/ICPC 라이브 스코어보드, 패널티, 동결, 공식 스냅샷 추가
- 문제 공개를 프로젝트 DAG 완료 노드와 연결할 수 있도록 통합
- 문제 제작소, 대회 참가·제출·스코어보드, 운영자 채점 콘솔,
  오케스트레이션 관제실 웹 화면 추가

- 외부 Google Fonts 의존성을 제거해 오프라인 프로덕션 빌드 지원
- 기존 손상된 프로젝트 상세 화면과 한글 내비게이션 복구
- 전체 기존 백엔드 회귀 테스트 및 새 코어 시나리오 테스트 통과
